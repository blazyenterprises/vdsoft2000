VDSoft2000 0.6.0

Experimental U.S. English formant synthesizer for NVDA by Brandon Henderson.
Nine voices: Derik, Jeff, Roxanne, Josie, Child, Alien, Robot, Old Man,
and Old Lady. Audio is generated by a custom source/filter engine.

INSTALLATION
Open dist/vdsoft2000-0.6.0.nvda-addon, install, restart NVDA, and select
VDSoft2000 under Speech settings. Choose a voice in the Voice list.

CONTROLS
Rate, Rate Boost, Pitch, Inflection, Volume, Roughness, Breathiness,
Head Size, Vocal Tract, and Gender. Rate Boost defaults off, Roughness
starts at zero, and the other controls default to 50. Output uses NVDA's
selected audio device through nvwave. Pause and cancellation supported.

STATUS
Testers have reported using it for daily speech. This remains an evolving
synthesizer: pronunciation guesses, unusual words and extreme settings may
need improvement. English only; Arabic is planned but not implemented.
Twenty-six automated engine/driver tests passed for this release. Driver
tests simulate NVDA; they are not a substitute for live NVDA testing.

DEVELOPMENT
Python 3.10 or newer, standard library only. From this directory:
  python build_addon.py
  python -m unittest test_engine test_addon
  python speak.py "Hello world." -o speech.wav
Run the build before driver tests to synchronize the packaged engine.
